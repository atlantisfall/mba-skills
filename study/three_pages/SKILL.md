# three_pages —— 学科精华「三页纸」

把一门课浓缩成「正文 ≤3 页 + 附录独立成页」的精华参考文档。源自 MBA 考前"三页纸"浓缩法：先确认学科骨架，再深化成稿。

## 何时使用
- 用户传入课程/学科名，想要学习或复习用的重点参考。
- 用户说"三页纸 / 浓缩 / 考前复习 / 重点提炼 / 学科精华 / 速查"等。
- 即使用户只给了一个课程名，也默认是本技能的场景。

## 输入
| 参数 | 必选 | 说明 |
|---|---|---|
| 课程名 | ✅ | 任意学科/课程名，如「组织行为学」 |
| 面向 | 可选 | `考试复习`（默认） / `工作应用`，影响优先级与内容侧重 |

## 全局规则（务必遵守）
1. **只使用可信来源**：检索、引用全部遵循 `references/sources.md` 的白名单 / 黑名单 / min-source 规则。**禁止百度系、内容农场、文档付费站**。
2. **抓取方式**：WebFetch 在本环境不可用 → 一律 **WebSearch 片段 + curl（浏览器 UA）** 取白名单页面。
3. **不硬编**：没有一手/二手来源支撑的内容，显式标注「未找到一手来源，需人工核实」，不得静默带过。
4. **透明**：用到本地缓存时，文档顶部标注「来自本地缓存 · 日期 X」。
5. **保存前征询**：产出 md / pdf 前，先确认保存位置。

## 两步流程

### 阶段一：概念框架表（定大方向）
1. 生成缓存键：`课程名(+面向)` → 目录 slug（可读形式，如 `组织行为学` → `zuzhi-xingwei-xue` 或直接保留中文）。
2. **查缓存** `~/.claude/cache/three-pages/<slug>/concept-table.md`：
   - 命中且不超过 12 个月 → **默认复用**，展示时顶部标注「来自本地缓存 · 日期 <缓存头日期>」；用户可要求**强制刷新**（跳过缓存，重新检索）。
   - 未命中 / 过期 / 强制刷新 → 按 `references/sources.md` 的 query 模板检索白名单源，合成候选概念表。
3. 输出概念表，格式：`| 子主题 | 核心概念 | 关键理论家/理论 | 优先级(P1/P2/P3) |`。
   - 骨架按学科共识结构组织（如组织行为学用 个体→群体→组织；其他学科按其课程大纲结构）。
   - 面向=考试复习 → 高频考点标 P1；面向=工作应用 → 应用性强的主题标 P1。
4. **用户确认/修正**：可多轮迭代（无硬性上限），每轮只产出修订后的表格；用户确认后进入阶段二。
5. **写缓存**：确认后的概念表写入 `~/.claude/cache/three-pages/<slug>/concept-table.md`，文件头含 `生成日期:` 行。

### 阶段二：深化成稿（三页纸）
1. 以确认的概念表为骨架，按一级子主题**并行派发 3–6 路检索子代理**（`/research` 语义：后台 → 白名单一手源 → 写带引用的 md 文件），各写 `research/<course-slug>/<subtopic>.md`。
   - 把 `references/sources.md` 的白名单/黑名单、query 模板、min-source 规则注入每个子代理的 prompt。
   - 强制子代理输出四段：`已覆盖概念（概念→来源URL→来源分级→置信度）/ 未覆盖概念 / 来源清单 / 盲区与失败`。
2. **覆盖矩阵**：主代理读取全部产出，映射概念表每行 → `✅ 已覆盖 / ◐ 部分覆盖 / ❌ 未覆盖`（含来源）。
3. 写正文（**≤3 页 A4**）：
   - 结构：课程地图（骨架概览）→ 分层次知识点（P1 优先、密度高）→ 高频考点速查表 → `⚠️ 覆盖盲区` → 附录。
   - 每个知识块尾部带引用标注 `[T1-<site>]` / `[T2-<site>]`。
   - 未覆盖子主题保留标题占位，标注 `⚠️ 未覆盖（原因：…）`，不静默丢弃。
4. **附录独立成页**（`page-break-before: always`）：来源 URL 表（标题/URL/访问日期/取数方式）+ 延伸阅读清单及链接。
5. **渲染 PDF**：用 `scripts/render_pdf.sh`（pandoc → HTML → Chrome 无头）。CJK 用系统字体，`@page A4` 控制页数。若正文超 3 页 → 调小字号（默认 9.2pt 密度档）或精简，直到 ≤3 页。
6. **保存**：征询用户，保存 md（源）与 PDF；默认放当前目录或 `outputs/<course-slug>/`。

## 缓存规则
- 只缓存**阶段一确认后的概念表**（阶段二成稿每次重新生成，不缓存）。
- 路径 `~/.claude/cache/three-pages/<slug>/concept-table.md`，文件头含日期。
- 复用时标注「来自本地缓存 · 日期 X」；超 12 个月提示「建议重新验证来源」；用户可强制刷新。

## 渲染与版式
- 样式 `references/render.css`（A4、字号 9.2pt、表格紧凑）；渲染脚本 `scripts/render_pdf.sh`（用法见脚本头注释）。
- 「3 页」= 正文 ≤3 页 + 附录另页；字号可调（9.2 密度档 / 9.6 标准档）。

## 错误处理与降级
- 子主题检索失败 / 仅二手 → 该行标 `❌ 未覆盖（原因）`，附录补「待补 / 延伸阅读」。
- 关键知识点不满足 min-source → 标「未找到一手来源，需人工核实」。
- WebSearch 不可用 / 网络受限 → curl 直取白名单；再失败 → 「模型知识底稿 + 未在线核验横幅」。
- 渲染缺 Chrome → 回退 `npx md-to-pdf` 或 `brew install typst`。

## 输出结构模板
```
# <课程名> · 三页纸精华参考
> 日期 · 面向 · 覆盖状态（如"部分内容来自本地缓存 · 日期 X"）
## 一、课程地图
## 二、<层次1>（P1 核心）
## 三、<层次2>
## 四、<层次3>
## 五、高频考点速查
## ⚠️ 覆盖盲区
# 附录（独立成页）· 来源与延伸阅读
```
