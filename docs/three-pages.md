# three-pages

## What it does

把任意课程/学科（组织行为学、市场营销、会计学、企业战略管理…）浓缩成「正文 ≤3 页 + 附录独立成页」的精华参考文档（"三页纸"）。

两步流程：

1. **阶段一**：产出概念框架表（子主题 / 核心概念 / 关键理论家 / 优先级），供你确认或修正；
2. **阶段二**：按确认后的骨架并行检索白名单来源，深化成稿（md + PDF），带来源引用（`[T1-x]/[T2-x]`）与覆盖盲区标注，附录独立成页列出来源与延伸阅读。

## When to reach for it

- 传入课程/学科名，想要学习或考前复习用的重点参考。
- 说"三页纸 / 浓缩 / 考前复习 / 重点提炼 / 学科精华 / 速查"等。
- 可选参数：`面向` = `考试复习`（默认）或 `工作应用`，影响优先级与内容侧重。

**用法示例（隐式调用——自然语言触发）：**

```
把组织行为学做成三页纸复习资料
浓缩《市场营销》，面向工作应用
我学完了人力资源管理但都忘了，帮我整理一份三页以内的重点速查
```

**用法示例（显式调用——直接指定技能）：**

```
/mba-skills:three-pages 组织行为学
```

> 若把技能安装为独立技能（而非通过插件安装），可去掉插件前缀：`/three-pages 组织行为学`。

## Prerequisites

- 联网可用（WebSearch / curl 检索白名单来源）。
- 渲染 PDF 需要 `pandoc` + Chrome（macOS 系统字体渲染中文）；无 Chrome 时回退 `npx md-to-pdf`。
- 概念表缓存在 `~/.claude/cache/three-pages/<课程>/`，默认复用，超 12 个月提示重新验证来源。

## Common questions

- **为什么不用百度？** 技能内置白名单/黑名单策略：只允许高可信来源（MOOC 课程大纲、教育部、权威出版社、学术数据库），百度系 / 自媒体内容农场 / 文档付费站一律排除。
- **3 页装不下怎么办？** 字号可调（默认 9.2pt 密度档），正文 ≤3 页、附录独立成页不占正文篇幅。
- **内容可信吗？** 每个关键知识点须 ≥1 一手或 ≥2 二手来源支撑；无来源处显式标注「未找到一手来源，需人工核实」，不硬编。

## It's working if

产出了概念框架表 → 你确认后 → 深化稿 → PDF（正文 ≤3 页 + 附录另页），带 `[T1-x]/[T2-x]` 引用标注与「⚠️ 覆盖盲区」标注，并征询你的同意后保存 md / PDF。

## Where it fits

mba-skills 技能集的第一个学习类技能（`study/` 类）。定位是「MBA 如何学」：把一门课浓缩成考前/应用可用的精华。后续可扩展：课程→框架模板、复盘类、应用类技能。
